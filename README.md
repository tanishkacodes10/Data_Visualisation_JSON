# JSON Assignment

## 📌 About
This repository contains my JSON assignment as part of the **Data Science and Visualization (DSV)** subject.

JSON (JavaScript Object Notation) is a lightweight data format used to store and exchange data. It represents data in a structured and readable format using key-value pairs.

## 🎯 Objectives
- Understand the basics of JSON.
- Learn JSON syntax and structure.
- Create and read JSON data.
- Work with JSON objects and arrays.
- Convert JSON data into Python objects and vice versa.
- Load and process JSON files using Python.

## 🛠️ Tools & Technologies
- Python
- Google Colab / Jupyter Notebook
- JSON
- Pandas

## 📚 Topics Covered
1. Introduction to JSON
2. JSON Syntax and Structure
3. JSON Objects
4. JSON Arrays
5. Reading JSON Data
6. Writing JSON Data
7. JSON Parsing
8. JSON and Python Data Conversion
